Getting started with gratia

{gratia} provides plots, predictions and diagnostics for generalized additive models (GAMs). This introduction fits a GAM, plots its smooth terms, extracts the values behind those plots and checks the model’s residuals.

First load gratia and make {mgcv}’s model-fitting functions available.

library("gratia")
load_mgcv()

We simulate 400 observations with four independent covariates sampled uniformly between zero and one. The response combines nonlinear effects of x0, x1 and x2 with independent Gaussian noise of standard deviation 2. x3 has no effect on the response. This gives us known patterns to look for in the fitted smooths, including a covariate whose contribution should be close to zero.

df <- data_sim("eg1", seed = 42)

Fit one smooth for each covariate. Restricted maximum likelihood (REML) estimates the smoothing parameters, which control how strongly the fit penalises wiggliness in each smooth.

m <- gam(y ~ s(x0) + s(x1) + s(x2) + s(x3), data = df, method = "REML")

Plot the contribution of each smooth

Use draw() to plot the four fitted smooths. The pointwise credible intervals show uncertainty at each plotted value of the covariate.

draw(m)

Each panel shows one smooth’s contribution. Add the four contributions and the model intercept to obtain the fitted mean for this Gaussian identity-link model. The smooths are centred so that the intercept represents the overall level. For models with other links, add the contributions and intercept on the link scale, then apply the inverse link to obtain the fitted mean.

The smooth for x3 lets us check how the model handles a covariate with no true effect. Its fitted curve can depart from zero because of sampling variation, and its interval shows the uncertainty in that departure.

Use a {ggplot2} theme to change the appearance of the plots. The & operator applies the settings to every panel.

library("ggplot2")
draw(m) & theme(
  geom.gratia.smooth = element_geom(colour = "forestgreen", linewidth = 1.5),
  geom.gratia.interval = element_geom(fill = "forestgreen")
)

Extract smooth estimates and build a plot

smooth_estimates() returns the values used to draw the curves, so you can inspect them or choose your own ggplot2 layers. By default it evaluates each smooth over an evenly spaced covariate grid.

sm <- smooth_estimates(m)

smooths(m)

Add interval limits with add_confint(), then draw the estimates as a line and the interval as a ribbon. The output columns map directly to the ggplot2 aesthetics in this example.

sm |>
  add_confint() |>
  ggplot(aes(y = .estimate, x = x2)) +
  geom_ribbon(aes(ymin = .lower_ci, ymax = .upper_ci),
    alpha = 0.2, fill = "forestgreen"
  ) +
  geom_line(colour = "forestgreen", linewidth = 1.5) +
  labs(
    y = "Partial effect",
    title = expression("Partial effect of" ~ f(x[2])),
    x = expression(x[2])
  )

Check the fitted model

Use appraise() to look for features the model has failed to describe, such as residual spread changing with the fitted mean or departures in the tails.

appraise(m)

Read the panels from left to right, starting with the top row.

  • a quantile-quantile (QQ) plot of deviance residuals,
  • a scatterplot of deviance residuals against the linear predictor,
  • a histogram of deviance residuals, and
  • a scatterplot of observed vs fitted values.

The data were simulated with Gaussian errors of constant variance, so we expect roughly constant residual spread and no systematic pattern against the linear predictor. Departures from the reference in the QQ plot can reveal where the observed residuals differ from what the fitted model would produce.

Add partial residuals to a smooth plot to compare the fitted curve with the observations after removing the estimated contributions of the other terms. For example, a consistent bend in the points around a flatter fitted curve can suggest that the smooth has missed part of the relationship.

draw(m, residuals = TRUE)
